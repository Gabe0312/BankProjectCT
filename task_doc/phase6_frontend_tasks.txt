  DATA SERVICE PATTERN
  --------------------
  - api.js is the single Data Service layer (no raw Axios calls in components)
  - Axios instance attaches JWT from localStorage to every request:
      Authorization: Bearer <token>
  - Axios response interceptor:
      -> 401 Unauthorized -> clear localStorage, redirect to /login
      -> 403 Forbidden    -> show "Access denied" message
      -> other errors     -> return structured { error: detail } to caller
  - Every exported function returns { data } on success or { error } on failure
  - Pages consume the service, check for error, set loading/error state

=======================================================
AUTH RULES
=======================================================

  - Username "admin" is reserved — no customer can register with it
  - Admin account is seeded directly in MongoDB (not via register endpoint)
  - Passwords stored as BCrypt hash ONLY — never plain text
  - Server generates JWT on login containing: { username, role, customer_id }
  - Two token types:
      AdminToken    (role: "admin")    -> grants /api/admin access
      CustomerToken (role: "customer") -> grants /api/customerDashboard/{id} only
  - role: "admin"    -> access to all admin pages only
  - role: "customer" -> access to customer pages only, scoped to their own data
  - localStorage stores: { token, role, customer_id, username }
  - Axios attaches token as Authorization: Bearer <token> on every request
  - ProtectedRoute checks localStorage on every protected page load
  - Logout clears localStorage and redirects to /welcome
  - Auth progression reference: Basic Auth -> JWT -> OAuth
