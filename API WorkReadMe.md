# Banking System — API Work

**Date:** July 16, 2025

A FastAPI backend REST API for a banking system built with Python, following MVC architecture.

---

## Tech Stack

- **Backend:** Python + FastAPI
- **Data Store:** In-memory (Python dicts) — temporary until MongoDB Atlas is connected
- **Validation:** Pydantic
- **Password Hashing:** bcrypt (Phase 8)
- **API Docs:** Swagger UI (auto-generated by FastAPI)
- **Testing:** Swagger UI + Postman

## MVC Architecture

```
HTTP Request → Controller → Service → Repository → store.py → HTTP Response
```

| Layer | File | Responsibility |
|---|---|---|
| Controller | account_controller.py | Receives HTTP request, unpacks inputs, returns response |
| Service | account_service.py | Enforces business rules, orchestrates data flow |
| Repository | account_repository.py | Reads and writes accounts to store.py |
| Repository | transaction_repository.py | Reads and writes transactions to store.py |
| Store | store.py | In-memory data store (temporary, replaced by MongoDB in Phase 5) |

## REST API Endpoints

Base URL: `http://127.0.0.1:8000`

| Method | Endpoint | Description |
|---|---|---|
| POST | /api/accounts | Create a new account |
| GET | /api/accounts/{id} | Get account details |
| POST | /api/accounts/{id}/deposit | Deposit money |
| POST | /api/accounts/{id}/withdraw | Withdraw money |
| GET | /api/accounts/{id}/transactions | Get transaction history |

### Create Account
`POST /api/accounts`
```json
{
  "userId": 1,
  "accountType": "SAVINGS"
}
```

### Get Account Details
`GET /api/accounts/{id}`
- No request body needed
- Returns full account object

### Deposit Money
`POST /api/accounts/{id}/deposit`
```json
{
  "amount": 500
}
```

### Withdraw Money
`POST /api/accounts/{id}/withdraw`
```json
{
  "amount": 200
}
```

### Transaction History
`GET /api/accounts/{id}/transactions`
- No request body needed
- Returns list of all transactions for the account

## Business Rules

| Rule | Enforced In | How |
|---|---|---|
| Deposit amount must be positive | account_service.py | Raises 400 if amount <= 0 |
| Withdrawal amount must be positive | account_service.py | Raises 400 if amount <= 0 |
| Cannot withdraw more than balance | account_service.py | Raises 400 if amount > balance |
| Every deposit/withdrawal creates a transaction record | account_service.py | transaction_repo.append() called on every operation |
| Transaction records are never deleted | entire codebase | No delete method exists anywhere |

## Configuration

### config.py
Loads environment variables from `.env`:
- `MONGODB_URL` — MongoDB Atlas connection string
- `DATABASE_NAME` — database name (default: bank_db)

### .env
```
MONGODB_URL=mongodb+srv://<user>:<password>@cluster.mongodb.net/bank_db
DATABASE_NAME=bank_db
```
Never commit this file to git — it contains credentials.

### database/db.py
Scaffolded Motor async MongoDB client. Not active yet — wired in Phase 5 when MongoDB Atlas is connected.

## How to Run

1. Navigate to the backend folder:
```bash
cd backend
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Start the server:
```bash
uvicorn app.main:app --reload
```

4. Open Swagger UI:
```
http://127.0.0.1:8000/docs
```
